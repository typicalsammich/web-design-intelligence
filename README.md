# Web Design Intelligence

A reusable design-intelligence system for creating distinctive, professional websites without forcing every project into the same visual template.

## Purpose

This repository is a decision and quality layer, not a website template. New projects should derive their art direction from the business, audience, content, market, brand assets, and conversion goal.

## Source influences

- UI/UX Pro Max — broad UI/UX design knowledge, style exploration, typography, color, responsive and interaction guidance.
- Frontend Design — context-fit art direction, accessibility, responsive behavior, complete states, and rendered verification.
- Meng To Skills — optional specialist inspiration for interaction, animation, atmosphere, composition, and advanced visual techniques. Never a default requirement.
- Vercel Web Design Guidelines — independent post-build interface audit.

This repository synthesizes principles and routing rules rather than copying third-party skill repositories wholesale. Original source licenses and upstream repositories remain authoritative for their material.

## Core principle

> If changing only the logo, colors, photos, and copy could make a finished site believable for an unrelated company, the art direction is not distinctive enough.

## Workflow

1. Understand the business and users.
2. Establish a project-specific creative brief.
3. Choose a visual thesis and interaction thesis.
4. Build the complete responsive experience.
5. Inspect the rendered site on desktop and mobile.
6. Run an independent design/UX/accessibility audit.
7. Fix meaningful findings.
8. Re-render and verify before delivery.
