# Uniqueness Audit

Run this on the rendered site before the conventional quality audit.

## Brand-swap test

Could the site become convincing for an unrelated company by replacing only:

- logo/name
- colors
- photos
- copy

If yes: **FAIL**. Rework composition/art direction.

## Structural repetition test

Compare against recent sites when available. Flag repeated combinations of:

- same hero geometry
- same header/nav treatment
- same service-card grid
- same section order/rhythm
- same image/text alternating pattern
- same CTA blocks
- same review presentation
- same footer composition
- same mobile stacking pattern
- same animation language

Individual familiar patterns are fine. Repeating the whole design grammar is not.

## Signature test

Can a reviewer identify at least one meaningful visual/compositional idea that belongs specifically to this project and is connected to the brand/content?

If no: **FAIL** for substantial new marketing sites.

## Decoration test

For each unusual effect, ask what it contributes: hierarchy, information, affordance, continuity, atmosphere, or brand expression.

If the answer is only 'it looks modern/cool': remove or justify it.

## AI-cliche scan

Flag clusters of generic patterns, especially:

- repeated rounded cards
- decorative pills/badges
- gratuitous gradients/glows
- generic icon + heading + paragraph grids
- arrows appended to every CTA
- oversized centered hero by default
- uniform section spacing/rhythm
- meaningless floating shapes
- stock imagery used as filler

A single justified occurrence does not fail the site. A design built primarily from these defaults does.

## Mobile identity test

Does mobile retain the same brand character and signature idea, or does it collapse into a generic vertical document?

If the identity disappears: **FAIL** and redesign the mobile composition.

## Result

Record PASS/FAIL for:

- Brand-swap test
- Structural repetition test
- Signature test
- Decoration test
- AI-cliche scan
- Mobile identity test

Any failed brand-swap, signature, or mobile-identity test requires design revision before final delivery.
